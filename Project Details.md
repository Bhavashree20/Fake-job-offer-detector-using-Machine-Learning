# Project Details

## 1. Project Title

**Fake Job Offer Detector Using Machine Learning**

---

## 2. Problem Statement

The increasing number of online job portals has led to a rise in fraudulent job postings. These fake job offers often mislead job seekers, resulting in financial losses and misuse of personal information. This project aims to develop a Machine Learning-based system that automatically detects and classifies fake job postings.

---

## 3. Project Objectives

- Develop a Machine Learning model to identify fake job postings.
- Analyze job descriptions and company information to detect fraud.
- Classify job postings as genuine or fake.
- Help job seekers avoid fraudulent job opportunities.
- Improve trust in online recruitment platforms.

---

## 4. Module List

### Module 1: Data Collection
- Collect real and fake job posting datasets.

### Module 2: Data Preprocessing
- Handle missing values.
- Remove duplicate records.
- Clean and prepare text data.

### Module 3: Feature Extraction
- Extract important features from job descriptions.
- Convert text into machine-readable format.

### Module 4: Model Training
- Train Machine Learning algorithms.
- Evaluate model performance.

### Module 5: Prediction
- Predict whether a job posting is real or fake.

### Module 6: Result Analysis
- Display prediction results.
- Calculate accuracy and other performance metrics.
